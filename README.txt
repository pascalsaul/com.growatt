Growatt Advanced is an independent, unofficial community integration for Homey Pro. Monitor Growatt solar inverters, energy meters and battery systems with enhanced battery diagnostics.

The first actively validated combination is Growatt SPH/MIX with ARK-XH high-voltage battery. This preview includes 14 additional read-only BMS measurements/alarms and a read-only API diagnostic for AC charge settings. Support for other Growatt models remains possible, but has not been verified for the new app.

Dynamic energy tariffs and optimization are intentionally left to Homey Flows and energy-management apps. Grid charging control is NOT available in this preview; it requires device-specific API verification.

This is a separate Homey app (nl.community.growattadvanced). It does not replace or migrate existing com.growatt devices, Flows or Insights. Credit: original GPL-3.0-or-later integration by R.M. de Gruijter; further modifications by Growatt Advanced contributors.
